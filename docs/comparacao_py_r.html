Comparações Python e R

  • R: linguagem feita por estatísticos; Python: uso geral
  • R é linguagem funcional, Python é POO?
  • Na verdade, R é predominantemente funcional, Python é predominantemente POO
  • R possui pipe nativo e o magrittr; Python possui método encadeados
  • R é vetorizado, o que significa menos loops, menos código escrito
  • Identação: Python:importa; R:não importa
  • Ambientes virtuais: Python: crucial; R: menos importante.
  • Muitas pessoas preferem não escolher entre uma e outra, mas usar ambas em diferentes partes do workflow.

Tipos de POO

Terminologia de Chambers. “Extending R”, 2016

OOP encapsulada (POO clássica ):

  • objetos contém dados e métodos
  • Métodos pertencem a objetos e classes
  • object.method(arg1, arg2).
  • encapsulada pois o objeto encapsula dados e comportamento (métodos).
  • Objetos são mutáveis

POO funcional:

  • objetos contém dados
  • Objetos não são mutáveis
  • Métodos pertencem a funções genéricas
  • Chamada de método padrão generic(object, arg2, arg3)
  • funcional pois, vista de fora, parece chamada normal de função e internamente, seus componentes também são funções.

Salvando objetos em disco

R

saveRDS(nome_objeto, "nome_do_arquivo.Rds")
nome_objeto <- loadRDS("nome_do_arquivo.Rds")

Python

with open("nome_do_arquivo.pkl", "wb") as file:
    pickle.dump(nome_objeto, file)

with open("nome_do_arquivo.pkl", "rb") as file:
    nome_objeto = pickle.load(file)
nome_objeto.to_pickle("nome_do_arquivo.pkl")
nome_objeto = pd.read_pickle("nome_do_arquivo.pkl")
